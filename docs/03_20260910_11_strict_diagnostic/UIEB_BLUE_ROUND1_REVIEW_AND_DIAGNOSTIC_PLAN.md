## 1. 目标、结论与证据边界

实验目标是将 DCTTA 框架迁移到水下图像增强，以 NU2Net 替换 PromptIR，在弱蓝色色偏源域监督训练，再利用强蓝色色偏目标 raw 做无参考监督的适配。

第一轮结论：源训练正常完成，后期验证进入平台并有轻度过拟合迹象；当前 DCTTA/NU2Net/数据/配置组合发生显著负迁移。现有证据不足以断言强弱域没有分开、NU2Net 容量不足，或 DCTTA 方法本身不适用于所有 UIE 场景。

后续顺序：核验数据和评价 → 复现第一轮 → 保持原更新流程采集诊断信息 → 用受控对照定位机制 → 针对证据改良 UIE 方法。

不能诚实地承诺一次诊断能“100% 找到全部根因”。本文将已识别的方案漏洞转换成明确的记录项和验收条件。满足验收条件，意味着诊断数据可靠、关键过程可以重放；不意味着假设已被证明。未通过时应报告缺口，不能以主观信心替代证据。

### 2.2 源训练与模型选择

- NU2Net 随机初始化，basic_channel=64、残差和 norm tail 保持原实现。
- 配对 RandomResizedCrop：面积比例 0.08～1，长宽比 3/4～4/3，PIL bicubic 缩放至 256×256；同步水平/垂直翻转。小图因此可以参与源训练。
- L1；Adam，lr=1e-3，batch=16，workers=2，250 轮，每轮 7 次更新，共 1750 次更新。
- 余弦周期换算为总更新次数；按源验证平均 PSNR 保存 best，同时保留 last。
- 源验证完整图输入，内部补齐到 8 的倍数，输出裁回原尺寸。

### 2.3 目标适配与评价

- 三组从同一个源 best 出发：Source-only、Source-only+x8、DCTTA。
- 目标裁剪边长 `8 * floor(min(320, H, W) / 8)`；104 张裁 320，29 张使用较小裁剪，最小 152。不插值、不大幅补边、不丢弃样本。
- 裁剪由 seed=23 和样本 ID 确定；batch=1，固定随机顺序，133 次学生更新。
- 当前配置：学生 Adam lr=2e-4；teacher_weight=5；教师 EMA=0.45；Fisher 逐张量保护比例=0.6；置信度等效全 1。
- RDDM 跨图持续训练，每张 5 次优化与 5 步采样；其优化器和 EMA 连续保留。
- 最后一个学生模型评价全部目标图。不是每张图刚适配后的在线结果，也不是完全未接触的目标测试集。
- 完整图评价，pad8 后裁回原尺寸；RGB 浮点指标，统计前 clip[0,1]，不以保存后的 8-bit PNG 替代浮点预测计算。
- 目标 reference 只用于文件核验和离线评价，不进入 Fisher、教师、RDDM 或学生损失。

“保持原仓库核心执行逻辑”与“严格按论文实验配置复现”必须区分。此前审查记录论文与本地原代码在 EMA、损失系数、感知损失和 Fisher 定义等方面存在差别；正式诊断前应依据正文、补充材料和实际调用代码重新核对，不把差异默认为迁移引入的错误。见 [既有审查](../../../DCTTA_ADAPTATION_REVIEW.md)。

### 3.1 源训练

| train L1 | 0.054142 | 0.052418 |
| val L1 | 0.070295 | 0.071706 |
| val PSNR / dB | 21.972640 | 21.701590 |

101～125 轮和 226～250 轮平均验证 PSNR 分别为 21.731119、21.691692 dB，仅相差约 0.0394 dB。后期训练损失继续下降，验证大体在平台附近；峰值到末轮的 0.2711 dB 差异不能全部解释为持续恶化。训练增强与完整图验证不在同一输入条件下，不能直接把 L1 差视作泛化差距。

250 轮日志连续、数值有限；best/last 历史与日志一致，严格加载正常；学习率按配置降到 0。下一步继续使用 119 轮 best，无需因这次目标负迁移直接重训。

### 3.3 完整性与 Fisher

三组 complete，源权重身份、目标清单、模型配置、评价协议和逐图输出尺寸一致；133 次适配包含 133 个不同样本。回传 best 和清单的实际哈希匹配报告。

最终适配权重有限。Fisher 保护 1,887,542 / 3,145,923 个候选参数元素（约 60%），这些位置最终全部等于源参数；其他 1,258,381 个元素发生变化。这证明恢复操作执行了，不能证明保护位置对 UIE 有效，也不能排除其他实现问题。

## 4. 对数据域和源模型能力的批判性判断

### 4.1 两域平均 PSNR 接近，不等于两个域相同

21.9726 来自参与模型选择的 27 张源验证图，21.7606 来自另外 133 张目标图。内容、分辨率、曝光、其他退化和参考风格混杂，均值接近不能独立判断域间距离。源验证最佳 checkpoint 的选择亦使两者并非对称比较。

现有强弱划分使用 CLIP 分数的类别内中位数；两侧样本可能紧邻阈值。脚本先缩放 256×256，再分 32×32 网格，实际每块 8×8，之后进入 CLIP 预处理。应检查它是否主要测量蓝色区域占比，而非可恢复的蓝色色偏。此处是对测量有效性的假设，尚未证明评分失效。

核验内容：原始未取整评分、分数分布、阈值边距、整图与局部评分稳定性、raw RGB/Lab/曝光/对比度描述量、分辨率与场景组成，以及不看模型结果的人工样本审查。由同一个分数切出来的分组，分数可分是构造结果，不能作为独立有效性验证。不要把无参考质量分数或“蓝色少”视为物理真值。

可以后续按预先固定的评分尾部和独立核验建立挑战子集，但不按源模型低 PSNR、TTA 改善幅度或最终失败图片挑选。不得覆盖原清单；更强子集属于新增开发实验，不能消除本次负结果。

### 4.2 21.9 dB 不足以判定 NU2Net 容量不够

只有 105 对源训练图片；1750 次更新、参考差异及裁剪统计都可能限制表现。必须计算 raw 基线与源模型增益，并用相同完整图协议评价源训练和验证：

- 训练图也改善很小：检查优化、数据匹配、输出范围及表示能力，不能直接认定欠拟合。
- 训练图改善明显、验证改善小：优先考虑样本量、分布和泛化。
- 完整图弱、相同区域独立裁剪强：优先检查上下文和归一化。
- raw 已很接近 reference：PSNR 上升空间和任务定义需重新理解。

不把当前小数据划分成绩与其他论文的不同数据量、划分、评价尺寸的成绩直接比较。UIEB reference 的构建质量和风格需要逐图核查；此前同图不同参考的实例是本批数据需要审计的具体理由，不代表全部参考都不可信。

## 5. 根因假设及必须收集的证据

| 假设 | 当前依据/局限 | 所需证据 |
|---|---|---|
| 评价或数据错误 | 已有身份检查通过，尚未在程序机独立重载复算 | 原图哈希、配对尺寸、浮点重算、保存图与浮点指标差异 |
| 伪标签与教师漂移 | 教师每步吸收 55% 新学生；置信度全 1 | 固定观察图上的教师/学生/源输出时间曲线；八视图分歧；冻结教师对照 |
| RDDM 早期生成不可靠或条件失配 | 在线每图仅 5 次更新；训练和采样的条件角色不同 | 训练 x_start/x_input、残差、噪声、采样各步、在线与 EMA 差异、冻结输入重放 |
| 优化目标存在错误的一致解 | 汇总 loss 下降但最终质量下降 | 固定样本误差、分量梯度、输出方差和颜色/结构变化；不能只看总 loss |
| 更新过强或输出层敏感 | NU2Net 迁移了原超参数，大量卷积元素可变 | 每层梯度、Adam 实际更新、Fisher 后有效更新、输出影响 |
| Fisher 重要性不适合 UIE | 重要性来自视图一致性，保护执行不等于正确 | Fisher 非零分布、topk 边界/并列值、逐层保护、受保护/未保护方向的输出敏感性 |
| norm tail/InstanceNorm 与裁剪上下文耦合 | 全图与 patch 使用不同空间统计 | 同一区域两种输入方式、tail 前后张量、极值触发状态、颜色量程 |
| 跨图状态与顺序累积 | 仅有最终评价，教师/RDDM/优化器连续 | 每步固定观察图评价、完整状态重放、必要时顺序或历史隔离 |
| 原代码、论文与实际依赖不一致 | 既有审查记录差异；程序机依赖未完整锁定 | 三方对照表、依赖版本及实际源码身份、实际执行配置 |

RDDM 方向是优先审计对象：当前 `train(raw, pseudo)` 经列表传入后，`x_start=raw`、`x_input=pseudo`，残差为 `pseudo-raw`；采样条件为 raw。这是当前原仓库行为，可能是再退化设计的一部分，不能未经论文和调用链核对就交换参数。

另外，`Trainer.test()` 调用的是扩散模型 `init()`。它会重设扩散相关系数，不能凭函数名认定它重置网络权重。必须记录调用前后参数和 buffer 的变化，区分在线模型与 EMA 模型的系数状态。

RDDM 的 EMA 与学生教师 EMA 是两套机制。前者由 ema_pytorch 控制更新间隔、预热和实际 decay；`ema.step` 增长不等于每步都混合权重，也不意味着实际 decay 始终是配置 beta。程序机安装版本与本地测试版本可能不同，需在程序机实测。

## 6. 旧诊断方案的漏洞与修订

| 旧方案不足 | 修订后的约束 |
|---|---|
| 漏读已有 jsonl，误以为无逐步损失 | 先读取所有已存在格式，列清已有/缺失证据，保留纠正记录 |
| 只保存总损失 | 六项原始及加权损失、学生梯度与实际参数更新分开记录 |
| 不同图片 loss 当成时间收敛 | 固定观察图离线逐步评价；区分当前图变化与固定样本变化 |
| 只保存 PNG | 数值诊断以原 dtype 浮点张量为准，PNG 仅预览，不单独归一化每张图来掩盖偏移 |
| 只保存若干最终模型 | 每步学生/教师快照；指定边界保存含 RDDM/优化器/RNG 的完整状态，可重放任意区间 |
| 只保证“相同 seed” | 同环境先验证短程确定性，再核对顺序、裁剪、初始化、噪声及全部关键状态 |
| 额外前向、采样或求梯度会改变轨迹 | 主流程只读取已有结果；额外计算在离线副本完成；诊断开关 A/B 验证 |
| 新诊断源码导致旧 Fisher 缓存身份失败 | 不绕过哈希检查；新代码单独重算并对照旧 Fisher 数值/掩码，差异先解释 |
| EMA 计数正确即视为状态正确 | 记录实际 copy/average/no-op、warmup、在线/EMA 差值和 buffer |
| 多个模块同时冻结后归因 | 从同一完整状态、同一已保存输入和随机状态做单因素对照 |
| 只看当前 crop 的更新收益 | 看同图完整预测和固定其他图片，发现跨图/跨尺度副作用 |
| 直接换 tail 或关闭 Fisher 当“修复” | 此类操作是算法变体/消融，单独命名，不写入原版诊断运行 |
| 新日志保存路径可能覆盖第一轮 | 独立诊断输出根目录，旧结果只读；不复用会覆盖 rddm/model.pt 的保存流程 |
| 声称一次完成根因定位 | 设数据有效性门槛与因果证据等级，未解释的结果明确列为未解决 |

## 7. 修订后的执行方案

### 7.1 阶段 A：静态核验、已有日志分析与基线补齐

保持源模型、清单和目标裁剪不变。需要在程序机读取完整 raw/ref；本地目前仅有部分原图及回传结果，不能假装本地已完成指标复现。

1. 固定第一轮文件与代码身份，核对所有原图、ref、CSV、best、adapted_model、Fisher 与 run.json。提取 Python、torch/torchvision、CUDA/cuDNN、驱动、GPU、numpy、Pillow、skimage、ema_pytorch、accelerate 的实际版本；记录确定性、TF32、AMP 和精度配置。
2. 使用原评价路径独立重载 best/adapted 权重，复算三组逐图指标。确认三组引用同一个 reference，通道/范围/补边/裁边一致；检查浮点预测先于 PNG 保存计算指标。
3. 计算 raw、源模型在源训练 105/源验证 27/目标 133 上的完整图逐图指标与改善量，另记录 RGB 通道误差、亮度误差、结构变化。不要把新指标加入适配损失。
4. 用源模型在相同图像区域做“完整图预测后取 crop”和“crop 单独预测”对照；另行观察固定 resize/crop 的效果，仅诊断，不改变正式评价口径。
5. 获取现有 severity_scores.csv、thresholds 及评分配置，关联 sample_id；缺少时域划分结论保持未定，不阻塞与评分无关的机制核查。重复场景人工审核记录不与旧清单混写。
6. 对齐原代码、迁移代码和论文定义，包括输出裁剪、感知/低频损失、教师 EMA、参数集合、Fisher 和 RDDM 方向。未解决差异先列清，不静默改成另一个算法。

### 7.2 阶段 B：先验证诊断本身不会改变结果

先运行同环境、无诊断的短程重复，确定基线数值可复现程度。再使用同一候选代码的诊断关闭/开启进行短程 A/B，固定数据和随机状态，至少覆盖 22 张目标图，以覆盖常见 EMA 100 次更新预热边界；若程序机 EMA 机制不同，按实际边界调整，并确保包含大小两类 crop。

验收内容不仅是最终 PSNR，还包括初始学生/教师/RDDM 参数、输入、裁剪、随机噪声、分项损失、学生/教师/RDDM 在线与 EMA 状态、优化器 step/m/v、Fisher、扩散 buffer 和 RNG 状态。

确定性配置下要求逐张量一致；若重复控制运行本身就存在 GPU 非确定性，必须先定位算子和量级，以重复控制的差异界定验收范围，报告未实现位级复现，不事后放宽阈值掩盖诊断引入的变化。不能单凭“PSNR 差不多”通过。

第一轮没有保存 RDDM 初始状态和完整环境，不能承诺精确重现第一轮轨迹。若新环境无法复现，先保留无诊断控制复跑结果，诊断只能解释可复现的新控制运行，须明确与第一轮的关系。

额外评估不在适配进程中运行；使用保存的副本离线计算。观测 hook 仅 detach/clone，不改变返回值、模块模式、buffer、梯度或全局随机状态，不把八视图合并 batch。计时可能因日志同步增加，不能把诊断耗时当原方法速度。

### 7.3 阶段 C：一次完整 133 步诊断重跑

不冻结教师、不调整学习率、不改变置信度、不重置 RDDM、不改变损失公式或 Fisher。每步仍是原先五次 RDDM 优化和一次学生优化。以下记录以真实执行事件为准。

#### C1. 每步的数据与身份

记录 run_id、全局适配 step（1～133）、sample_id、迭代编号、完整图宽高、crop 宽高及 top/left、图像/裁剪张量哈希、设备/dtype、八视图操作及逆操作。保留原顺序完整列表；不得依靠重新 shuffle 推测重放顺序。

#### C2. 教师、学生与再退化图

每步保存主流程已有的 raw crop、八视图逆变换后的教师结果及均值、再退化图、更新前学生 raw 输出、更新前学生再退化输出。保存浮点张量及统一 [0,1] 显示的预览；范围外比例从裁剪前张量统计。

每个张量记录逐通道 min/max、均值/std、1/50/99 分位数、非有限值、<0/>1 比例；给出明确定义的亮度代理 `0.2126R+0.7152G+0.0722B`（sRGB 数值加权，不称物理亮度）、颜色通道差和输出空间方差。对原输入/伪标签/再退化图记录有符号差值和绝对差值，分开内容结构与颜色变化，不以“更暗/更蓝”作为再退化合格条件。

离线从快照补算相同 raw 和相同再退化图上的“更新后”输出、冻结源输出、完整图输出。这些不能重新调用会训练或采样的 RDDM 接口。新旧教师和学生必须用清晰的 before/after step 标注。

#### C3. NU2Net 归一化与上下文

在已有前向中捕获残差相加后、norm tail 前后的张量/统计，记录条件分支是否触发及每通道 max−min。记录 InstanceNorm 配置、输入形状和关键层空间方差，必要的详细激活留在离线重放，不保存全部层的全部激活。

同一快照比较完整图预测后裁出区域与独立 crop 预测；按相同位置与有效区域比较，不能混入裁剪坐标变化。将源模型已有差异与适配新增差异分开。替换 tail、关闭 InstanceNorm 或改变 resize 仅属于后续消融，不能混进主重跑。

#### C4. RDDM 每张图的五次训练及采样

每个 RDDM 子步骤记录：局部 step、跨图累计优化 step、x_start/x_input 的角色和范围、目标残差、采样的 t、噪声张量身份、未缩放 L2 与实际反传损失、梯度裁剪前/后范数、优化器 lr/step 与实际更新幅度。当前代码将损失除以 gradient_accumulate_every 后每次都 step，应如实记录，不能把参数名误当成实际累积了两批，也不能在诊断时顺手修正。

采样记录：实际 condition、起始噪声及每个时间对、每一步 latent、预测残差/x_start、裁剪或截断前后统计、最终张量。只捕获原采样中的真实中间值，不额外调用第二次 sample。记录训练在线模型与采样 EMA 模型的权重差、系数 buffer 哈希及 `init()` 前后变化。

记录 RDDM EMA 的 beta、update_every、update_after_step、当前 effective decay、initted、累计 step，以及本次动作是 copy、average 还是 no-op；不把局部五步计数或 EMA step 当实际权重更新证明。安装依赖的实际实现是证据来源，不能将本地版本假设套到程序机。

#### C5. 损失、梯度和参数更新

每步记录六项原始损失和各自加权值：学生一致性的像素/VGG/低频三项，教师约束的同三项；再记录 loss_s、loss_t、总和以及权重。确认置信度全 1，并离线统计八视图分歧但不启用分歧加权。

主流程一次正常 backward 后记录逐层梯度范数、零/非有限值比例。在每层分别记录：更新前参数、Adam 后参数、Fisher 恢复后参数的差范数和最大差；相对范数用 `||delta||/(||theta||+1e-12)`，零/极小范数层同时报告绝对值，不能凭相对百分比单独判断。对保护与非保护位置分别统计。

检查非候选参数/缓冲区是否变化、保护位置是否精确等于源参数、教师是否在 Fisher 后才更新、优化器动量是否跨步持续。Fisher 保存逐层非零率、数值分位数、topk 截止值及并列值情况，不仅保存二值 mask。

分项梯度范数和夹角在离线重放中用冻结的 raw/伪标签/再退化图计算，保持同一模型状态，避免主训练额外 backward 干扰。选择预定检查点及首次异常区间，不必对全部 133 步做昂贵分项求导。梯度冲突只能支持机制假设，不能代替干预对照。

#### C6. 每步模型快照与固定观察样本

保存 step=0～133 的学生、教师 state_dict，原 dtype，无量化；step=0 是 Fisher 完成、RDDM 初始化后、尚未开始适配的边界。约 3.146M 元素模型，学生+教师 float32 权重合计约 3.37GB 十进制容量（不含其他状态），可压缩但不能假设压缩比。

固定观察集先选源验证 4 张、目标 12 张，按尺寸分层、样本 ID 哈希确定，名单在重跑前落盘，不看最终误差挑样本。已有 severity 分数时用于报告分层，不临时更改观察集。每步快照离线评价这 16 张，记录学生、教师、固定源模型的 PSNR/SSIM、颜色/亮度/结构差异；所有 reference 仅在独立评价进程打开。

在 0、1、5、10、20、40、80、133 步，对全部 133 张目标图和 27 张源验证图作离线完整图评价。固定观察图发现突变时，可离线补算该区间其他快照，无需重跑适配。当前图的更新前后效果单独记录，不能与固定观察图均值混成一条曲线。

这里的源图只是冻结观察对象，不进入优化；目标 reference 不用于早停、挑本次 best、改顺序或动态筛图。所有中途成绩属于事后机制分析，不作为正式“最佳 TTA”成绩。

#### C7. 可重放完整状态

在边界 0、1、5、10、20、40、80、133 保存完整状态：学生/教师、固定源身份、Fisher 值和 mask、学生 Adam step/m/v、RDDM 在线模型、RDDM EMA 模型及 wrapper 状态、RDDM RAdam 状态、所有扩散 buffer、两种计数器、混合精度 scaler（若有）、训练模式、Python/NumPy/torch CPU/全部相关 CUDA RNG、DataLoader generator、已消费顺序与下一位置、配置与实现身份。

快照在一次适配完整结束后、取下一批之前保存；必须保存或明确重建参数梯度状态。RDDM 梯度裁剪、归零时机、采样对 buffer 的影响不能遗漏。现有 adapted_model.pth 是推理权重，不能冒充完整在线断点。

每个区间可以从最近完整边界顺序重放到任意目标步，利用逐步输入/噪声哈希和学生/教师快照确认匹配。随机 t 和噪声记录支持定位差异；不能把只重放最终输入张量称为重现完整优化历史。

至少验证一个跨小图/大图且跨实际 EMA 更新边界的恢复区间，与不中断运行的模型、优化器、buffer、RNG 和输出一致，才能称“可重放”。

## 8. 如何从记录走向因果判断

先满足静态和轨迹验收，再按以下证据选择单因素实验，默认不一次全部运行。

| 观测 | 下一项对照 | 可以支持的判断及限制 |
|---|---|---|
| 禁止学生优化后输出仍变 | 固定源模型/模式/buffer/输入的纯前向控制 | 先排查评价或状态变化；不是学习率问题 |
| 首步再退化已严重异常 | 同一RDDM状态、固定噪声检查训练/采样条件与系数；先不更新学生 | 定位生成侧问题；不能只凭不自然外观证明方向应交换 |
| 生成图合理，但单次更新后完整图恶化 | 保存同一伪标签和再退化图，复制模型及Adam状态，对比零更新和原更新，必要时预定0.1倍步长 | 可检查更新方向/幅度；不是自动选出最佳学习率 |
| 教师随学生在固定图持续漂移 | 从同一初始化运行冻结源教师对照，其他设置固定 | 隔离教师反馈；若重新生成RDDM输入变化，属于完整链条效果，不能当直接梯度效应 |
| online RDDM与EMA差异大 | 冻结状态离线使用同一噪声比较两者输出 | 隔离EMA滞后/预热影响；不直接更换正式采样模型 |
| 裁剪正确、全图异常 | 同一模型同一区域的crop/full对照，含固定源模型 | 确认上下文效应；改变tail等需单列算法变体 |
| 后期才明显变差 | 从边界重放，定位首个异常更新；必要时一个预定顺序对照 | 区分累计漂移与局部触发；不扫描顺序找最好成绩 |
| loss各项均降而固定图质量降 | 固定输入做分项梯度与单项损失更新的离线对照 | 检查错误一致解、目标冲突；分项幅值本身不能证明主因 |

每个干预从相同完整状态开始，不共用已经更新过的优化器或EMA。直接更新效应实验复用已保存伪标签/再退化图；端到端实验允许这些中间结果随干预变化，必须明确区分。分支不得反向污染主运行，不以关掉teacher或Fisher后分数提高就宣布单一根因；若存在交互，按证据再补一个组合对照。

结论分三级：A 已确认实现错误（具体不变量违背并可复现修复）；B 有受控干预支持的机制（同状态、单因素、输出与指标证据一致）；C 仅关联/尚未解释。一个因素改善不能证明不存在第二个因素。若第一轮无法复现或恢复检查失败，优先报告复现障碍，不提前归因。

## 9. 验收与停止条件

诊断功能实施后，必须逐项给出通过/失败/未执行及证据路径：

1. 三组重载评价、raw/ref配对和数据身份可核验；缺失原图或严重度报告的影响范围明确。
2. 133 条学生记录与原顺序一致；正常完整运行665条RDDM优化记录；采样事件按实际执行逐一对齐，无遗漏或重复。
3. 每步浮点关键图、损失、有效参数更新、归一化状态和生成器状态可关联到同一个输入与step。
4. 诊断开关A/B及无诊断重复控制已通过；若仅在非位级精度上成立，误差来源和边界明确。
5. 每步模型快照与指定完整状态能读取，至少一段完整恢复重放验证通过，环境和依赖已锁定。
6. 固定观察曲线和预定全量离线评价齐全，评价不影响适配，不按目标分数选择停止点。
7. 第一轮负结果被保留；源码修正、日志改动、参数变化、算法变体分别记录。
8. 报告能够定位退化最早可观测阶段，给出支持/反驳证据；未定位则明确“证据不足”，安排针对性下一步，不声称100%找到根因。

若步骤2/3出现非有限值、状态计数异常、数据变化或保存失败，停止并保留证据；若只是评价指标下降，原配置诊断仍完成133步，除非资源/运行异常导致无法继续。避免用reference早停改变被诊断对象。

## 10. 后续方法改良与数据使用边界

用户已授权实施诊断，当前已完成本地代码与短程验证；不同时重训源模型、重分目标域或加入水下损失。正式数据上的执行状态以程序机各阶段输出为准。退化评分有效性、reference人工核查及依据结果开展受控干预仍需后续证据，不能用本地测试宣称完成。

有证据支持后再考虑：稳定源模型约束/可靠性筛选、限制有效更新、保持内容的水下再退化、全局颜色上下文等。强制减蓝、提亮或灰度世界不能默认正确，因为自然蓝水和真实暗区域可能被误改。

目标reference在诊断中只能由独立离线评价读取，不能作为在线梯度、样本权重、更新拒绝、早停或最优checkpoint选择依据。若据本批结果决定方法和超参数，这133张已成为开发数据；从同一已查看集合再挑子集不能恢复为未见测试集。最终验证需另设未参与方法选择的数据，并保留完整133张的第一轮失败结果。

建议执行范围：先 A；再完成 B 的记录可靠性和重放能力验收；随后执行 C 的一次完整重跑与离线分析。单因素隔离和方法改良依据报告另行确认。
