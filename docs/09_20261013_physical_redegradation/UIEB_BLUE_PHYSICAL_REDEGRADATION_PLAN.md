# 逐图独立物理再退化：预实验与两组TTA方案

日期：2026-10-13。状态：预实验已回传并核验，用户确认A方案，正式K=200、G6 γ=0.5/G7 γ=1。正式入口及11项正式TTA本地CPU测试完成；程序机CUDA验收与正式运行待执行。

## 1. 已确定的选择

- 退化形式采用物理启发的颜色衰减与背景光混合，不使用RDDM生成。
- 每张图单独拟合：退化参数与优化器状态都从相同固定随机初态重置，不跨图积累。
- 学生模型与学生优化器跨图累计更新，初始化为原源模型。
- 固定源教师同时提供退化拟合的增强候选和学生loss_t监督；不做教师EMA。
- 物理退化作用于原始raw，保留原DCTTA两路学生输出和一致性目标。
- 比较γ=0.5与γ=1两组。
- 已有10张典型图的训练步数预实验已完成，统一K=200已确认。
- 参数估计采用直接优化：三通道低分辨率衰减网格和每图三个全局背景光值；没有预测网络。

本方案取代此前“先训练所有目标图再TTA”的旧设想；不采用整批目标预训练。此前G6/G7教师用途交叉实验只是建议，尚未实现；本轮物理实验拟使用G6/G7，旧交叉建议不再以这两个编号作为当前执行计划。

## 2. 参数及退化公式

冻结源教师F，对当前适应输入I得到停止梯度的八视图增强候选J0=F_x8(I)。

待优化变量为a∈R^(3×h×w)和b∈R^3：

    tau_grid = tau_max * sigmoid(a)
    tau = bilinear_upsample(tau_grid, I.height, I.width)
    T = exp(-tau)
    B = sigmoid(b)，广播到整张输入
    I_hat = J0*T + (1-T)*B

预实验起始配置：h=w=32，T_min=0.1，tau_max=-log(T_min)。这些是工程起点，不是论文给出的最优配置或真实水体参数。tau表示有效衰减，不声称恢复深度或真实衰减系数。

初始化使用固定局部种子生成同一a/b模板，初始T接近恒等退化、B接近中间值；初始化不依赖reference，也不消费学生真实适应的随机流。具体数值、版本和SHA256在实现及预检时记录。

拟合后通过增量强度生成：

    T_gamma = 1-gamma*(1-T)
    x_sd = I*T_gamma + (1-T_gamma)*B

γ=0时恒等，γ=1时完整施加该变换；γ=0.5等价于原图与γ=1生成图的0.5凸组合。T/B取值有效时生成结果在[0,1]，无需最终硬截断；T很小仍可能压缩对比度，因此不能仅用范围合法判断质量。

用(J0,I)估计关系再施加在已退化I上，是额外退化增强，不是对清晰场景成像的直接物理复现。

## 3. 拟合目标与监督边界

第一版拟合使用RGB重建L1加低分辨率tau的空间平滑项：

    L_D = mean(abs(I_hat-I)) + lambda_tv * TV(tau_grid)

TV按横纵相邻元素绝对差归一化。lambda_tv的预实验起点为0.01；先不加入VGG、双透射、深度、噪声和对比模块。重建损失、TV项和总损失分开记录。优化器采用独立Adam，初始学习率0.05作为低维变量拟合的起点，与学生学习率完全分开。

若预实验发现震荡、参数持续触界或异常过度平滑，调整拟合配置后重新完整执行预实验并留存版本，不能仅按某张图的参考PSNR挑参数。本轮正式配置已经冻结，沿用预实验默认值，不按reference选择。

J0、I均不求梯度；仅a/b求梯度。reference只用于正式离线增强评价，不进入拟合、步数选择、强度选择或在线停止。

B限定为三个全局值，避免自由背景图复制输入；正T下界限制过强衰减。上述约束减少退化解，不保证参数唯一或物理真实。源教师伪标签错误仍可能被拟合到T/B中。

## 4. 训练步数预实验

使用visual_v2既有selected_samples.csv中的10张图片，保持身份固定。训练步数观察点初定为0、5、20、50、100、200；预实验观察点不表示各自独立重训；回传分析后用户已确认统一K=200。

为与现有TTA可比，主拟合使用原TargetRawDataset的同一确定性适应图块，最大320×320，小图按原协议自适应边长，不缩放。另保存整图诊断结果，整图拟合是额外观察，不替代真正参与适应的图块统计。

每张图一条从共同初态开始的拟合轨迹。在观察点保存训练图块原图I、源候选J0、重建I_hat、两种强度x_sd、T各通道及B值。可视化T与真实RGB图区分标注，不把T伪彩图当成生成RGB图。整图观察也记录独立拟合身份。

记录：重建L1及相邻预算的变化、TV、T分位数/下界附近比例、B值、梯度和参数有限性、各通道均值/标准差/边界比例及相对raw的变化，拟合耗时。

选择统一K时看10图的拟合稳定性、参数触界和生成有效性，不用目标参考PSNR选K。低损失不是唯一标准。若200步仍不稳定，先检查参数化和学习率，不能直接扩展到大量步数并宣布收敛。预实验已汇报并确认200步，正式配置已冻结；正式TTA不按每张图reference提前停止。

预实验阶段不更新学生，不把拟合阶段当成已经取得TTA收益。

## 5. 正式两组

| 组别 | 教师 | 退化拟合 | 强度 | 学生更新 |
|---|---|---|---|---|
| G6 | 固定源教师 | 每图从共同初态拟合200步 | γ=0.5 | 跨图累计 |
| G7 | 固定源教师 | 同样拟合200步 | γ=1 | 跨图累计 |

每组学生独立从同一源状态启动，不让G7接着G6训练。保持原133图顺序、确定性裁剪、学生Adam、两项损失、Fisher保护和源权重。拟合随机初态及K不依赖gamma，两组同图应产生完全相同T/B；只在施加退化时gamma不同。

每张图执行顺序：固定源八视图候选 → 重置并拟合a/b K步 → 固定a/b生成x_sd → 原图学生输出停止梯度 → 再退化学生输出参与梯度 → 原loss_s与固定教师loss_t → 学生Adam → Fisher恢复 → 下一张图。

第一版不做教师EMA。不将J0送入学生当作raw，不以物理重建I_hat替代真正的x_sd。学生原有一致性与教师监督作用对象保持可核对。

## 6. 评价与过程输出

最终全133张原始raw的学生增强y_in保存整图；全部27张源验证评价。主指标为PSNR/SSIM、相对source逐图增益、中位数、下降超过1dB数量、最差损害及源能力保持。

11个固定阶段使用原10张图，输出teacher_pseudo、x_sd、y_sd、y_in及指标。物理拟合只依赖固定源和同图输入，故同一完整图的阶段x_sd应保持不变；诊断拟合必须隔离学生状态和随机性，可以缓存固定输入结果减少重复拟合。整图与适应图块拟合分别标注。

训练记录保存真实图块的T/B、拟合损失、输入变化与学生更新摘要，不只依据诊断整图推断训练行为。每步可续跑；完整恢复状态包含学生、学生优化器、Fisher身份与随机状态。临时退化优化器不跨图继承。

新增输出目录使用独立physical_v1，不覆盖旧实验。磁盘预算沿用10 GB并进行预检；此数字不是显存或RAM保证。

## 7. 对照和解释范围

G5为工作参照，G3为稳健参照，G0为原迁移失败基线。现方案同时改变了生成形式、退化模型逐图重置和拟合预算；因此G6/G7优于G5也不能把收益全部分配给物理公式。

两新组之间只改变gamma，适合解释强度效应。若要隔离物理形式与重置方式，需要后续增加同样重置/访问规则的RDDM对照或其他严格预算对照，本轮不自动增加第三组。

冻结方案后，改良结论还需预先固定新顺序的同顺序对照，以及未参与方法选择数据的验证。当前目标集视为开发集。
