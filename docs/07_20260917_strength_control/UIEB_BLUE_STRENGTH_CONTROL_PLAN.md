# 再退化使用强度：两组受控实验方案

日期：2026-09-17。状态：用户已确认新增两组；本文件为实验协议，实验代码尚未实现，正式实验尚未启动。运行命令将在实现与验证后另写 RUN 文档，不能直接套用旧入口启动新组。

## 1. 目标与已有依据

保留全部133张目标图，检验减弱RDDM生成结果的使用幅度能否改善真实raw恢复，并区分它与教师EMA反馈的共同作用。主改良组从固定教师G1出发；对应EMA组用于检验该干预能否缓解G0的累积退化。不重训源模型，不重新挑选目标数据，不扫描多个强度。

现有全目标PSNR：source-only 21.7606，G0 14.8646，G1 21.8745，G2 21.2458，G3 21.8697 dB。G1与G3均值接近，但G1有73张下降、源验证下降约0.499 dB；G3有46张下降且源验证基本保持。G0实际再退化训练图块中103/133张红通道中位数为0，原raw为11/133。这是干预依据，但尚不能假定G1具有相同程度的颜色损失。

依据：[路径对照分析](../05_20260912_13_factorial/UIEB_BLUE_FACTORIAL_ANALYSIS.md)、[整图诊断分析](../06_20260914_15_visual_diagnostic/UIEB_BLUE_VISUAL_DIAGNOSTIC_ANALYSIS.md)。

## 2. 实验矩阵与命名

| 教师方式 | α=1 | α=0.5 | α=0 |
|---|---|---|---|
| 原EMA教师 | G0，复用 | G4：EMA教师，新增 | G2，复用 |
| 固定源教师 | G1，复用 | G5：固定教师，新增，主改良组 | G3，复用 |

两组均从原strict v2的第0步完整初态独立启动，不从G0/G1终态继续训练。建议先运行G5、再运行G4，两组间不得继承学生、生成器或优化器状态。旧G0–G3不进行新的完整运行；实现验收需要的小规模端点核对不计为新增正式组。

定义实际学生输入：

x_mix = (1 - α) * x_in + α * x_sd，α固定为0.5。

x_in是原实际训练raw图块，x_sd是原生成器采样并按既有流程处理后的浮点结果。二者形状、设备、范围一致，在原浮点精度下混合，不经PNG、额外归一化或新裁剪。有限且均在[0,1]时，凸组合无需新clamp；出现异常必须停止核查。

x_sd保留为生成器原始结果，x_mix作为学生第二路输入，两者不得混名。学生第一路仍接收raw，第二路的学生输出同时用于原一致性项与原教师项，原detach位置和全部损失权重保持不变。只改变输入，不对loss乘α，不改变RDDM训练对、训练步数、扩散采样步数或内部EMA。

G4保留原教师参数EMA；G5严格冻结源教师，使用原八视图伪标签逻辑。固定教师意味着对同一输入和处理协议输出固定，不意味着不同图片伪标签相同。α是像素混合系数，不等于物理退化程度或有效更新幅度减半。

α=0端点两路raw相同，一致性项为0；因此G2/G3是路径端点对照，不是保留等量一致性训练的弱退化版本。

## 3. 固定条件与实验身份

- 使用原133张target清单、相同顺序、每图一次更新、原确定性裁剪（上限320，按8倍数取可用尺寸）；不精简、不新增、不重复图片。
- 使用原源best权重、固定第一轮Fisher及其保护集合、相同NU2Net、Adam、学习率、损失权重、恢复规则和数值模式。
- 从 diagnostic_v2/run/replay_states/000000.pth 恢复学生、教师、RDDM、两类优化器、EMA、buffer和RNG；先核对其原始身份。依照既有严格协议检查初始化和运行环境，不能重算Fisher替代。
- 参考图只进入离线评价，不用于适配、早停、逐图α、选择最好阶段或强度搜索。本目标集已参与机制研究，作为开发评价集；最终泛化结论需要新数据。
- 记录代码提交、工作区是否干净、入口及核心文件哈希、源/Fisher/初态/清单身份、α、教师模式、随机种子、裁剪和设备环境。
- 保存新实验到独立目录 experiments/UIEBblue_weaktostrong_NU2Net_strength_v1/，内部区分G4/G5；此为拟定输出合同，旧目录只读。

随机控制：两组恢复同一初态，混合本身不引入随机数；诊断保存与额外评价必须隔离RNG和模型状态。G5与G1的生成器训练条件理论上相同，应在可用旧状态/记录上核对生成器轨迹及采样身份；不能仅凭同一个seed声称输入完全相同。G4的教师变化会反馈到生成器，后续x_sd与G0不同属于干预的总效应，不能强行替换成G0缓存来冒充原设计。

## 4. 记录与评价

### 4.1 主要评价

最终第133步统一评价完整目标133张与源验证27张：PSNR、SSIM、逐图相对source-only及对应原组的变化。报告均值、中位数、改善/下降张数、最差变化和下尾分位数；并预先统计PSNR下降超过1 dB的张数作为辅助风险指标。固定终态，不按目标指标选择中途最佳权重。

主要比较：G5对G1（减弱强度的改良效果）、G4对G0（EMA下能否缓解严重退化）。辅助比较G5对G3及source-only，判断保留非零生成输入是否提供实际收益。两组收益都按配对逐图结果报告，不能只凭平均PSNR略升宣称成功。

### 4.2 时序与真实训练输入

每步保存原loss_s/loss_t/总loss、实际参数更新范数和Fisher恢复幅度、状态/顺序核验信息。对raw、原x_sd、实际x_mix记录逐通道均值、标准差、分位数、精确0/1比例与预先固定近边界阈值（1/255）的比例；比较混合是否真正减少颜色压缩。精确边界和近边界统计分开，不能把PNG量化零值等同于浮点零值。

记录固定12张旧观察集的真实raw恢复曲线；在0、14、27、40、54、67、80、94、107、120、133阶段评价全部133张目标图和27张源验证图的学生输出，并评价目标教师八视图伪标签。使用统一整图口径；若复用旧组曲线，必须核对对应步骤和输出分支，不混用单视图教师与八视图伪标签。

复用上一轮10张CSV作为可视化观察集，只用于解释，不代表总体。阶段快照保存teacher_pseudo、原x_sd、实际x_mix、y_mix及学生raw输出；相同图片跨阶段使用固定诊断种子重新生成x_sd，明确它不是实际训练图块。PSNR计算教师、y_mix、学生raw输出，不给x_sd/x_mix设置恢复质量PSNR目标。G4/G5不要只保存y_mix而遗漏真实raw表现。

图像预算：每组10张×11阶段×5类=550张；另保存最终133张学生raw结果，每组683张，两组1366张（不另存160张每阶段评价图）。指标保留浮点PSNR和保存PNG的PSNR，说明量化差异。大型恢复状态另计，不把图片估算误当总磁盘或显存需求。

资源要求：实现时进行逐文件预算，两个新组新增输出合计以10 GB为上限；优先一个最近完整恢复状态加必要轻量记录，不默认每步永久保留完整RDDM。旧恢复文件清理如有必要须一次一个明确路径，禁止批量删除；不能静默超预算。预算不足时先调整保存策略并记录，再运行。整图生成使用已验证的诊断query分批注意力路径，不修改真实训练前向；仍需在程序机验证峰值显存。

## 5. 实现与验收要求

优先增加独立实验入口、复用既有诊断辅助能力，避免改动参与旧身份核验的算法文件；不直接把修改后的run_factorial_uie.py当成旧版本复现入口。

1. α=1/0的退化输入及更新端点分别对应原regen/raw分支；固定教师/EMA行为均有检查。小型真实RDDM测试覆盖实际更新，不只检查混合公式。
2. α=0.5确实进入两项损失的学生第二路；原生成结果不被原地修改，detach/梯度路径不变。
3. 同初态有无额外观测的实际更新状态一致；中断恢复与连续运行轨迹一致；已完成阶段不重复更新。
4. 输入身份或配置改变拒绝续跑；非有限值、预算不足明确停止，不覆盖旧实验。程序机核验通过后才运行两组正式133步。
5. 实现完成后给出独立运行说明、同步文件清单、Git提交身份和回传清单。当前文档不提供尚不存在的可执行命令。

## 6. 预先规定的解释边界

| 观察结果 | 后续判断 |
|---|---|
| G4、G5均有明确收益且颜色压缩减轻 | 支持原生成结果使用幅度过强参与问题，但尚未隔离颜色、难度与更新幅度 |
| G4大幅改善，G5变化不大 | 优先研究再退化输入与EMA反馈的相互作用 |
| G5改善，G4仍严重退化 | 可沿固定教师改良；简单减弱输入不足以稳定原EMA |
| 两组均无明确收益 | 不继续盲扫α，重新检查退化类型、目标匹配与教师约束 |
| 只有y_mix改善，真实raw/源验证不改善 | 不能认定适配有效 |
| G5与G3接近且没有分布或结构收益 | 尚无证据证明再退化路径带来额外价值 |

若改善主要伴随更新范数降低，再考虑一个预先定义的更新幅度对照；本轮不同时加入学习率搜索、教师EMA系数修改或颜色专用约束。即使红通道归零显著减少，也不能单凭该变化证明它是唯一原因。单顺序实验不推出跨顺序稳定性。
