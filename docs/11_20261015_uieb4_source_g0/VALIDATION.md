## 实现验证

`tests/test_uieb4.py`覆盖：

1. 组级分层计数、固定种子与不拆近重复组。
2. 清单冲突拒绝覆盖。
3. 快照选取不依赖目标PSNR，类别等权汇总。
4. 原子指针提交失败仍可读取上一个完整状态。
5. 完整入口中断、续跑、连续运行末态相同、完成后不重建模型及结果损坏拒绝。
6. 真实RDDM的生产构建路径：新Fisher冷计算／缓存加载初态完全一致，错误源身份缓存拒绝。
7. 真实RDDM适配：重复／观测隔离／状态恢复一致，四角色图片导出，跨EMA99→100边界。使用小型合成图和小NU2Net；不是正式CUDA验收。
8. 运行文件校验允许LF/CRLF差异，拒绝代码内容变化。

源训练回归覆盖合成数据源模型训练、轮次续训、best/last提交中断恢复、目标图不进入训练、配对增强一致性；另以真实RDDM跑通小型source_only／x8／adapt旧入口。数据复制回归覆盖奇数尺寸、alpha/JPEG原字节复制、损坏和跨端场景冲突拒绝。

本轮最终测试集为 `test_uieb4`、`test_source_training`、`test_uieb_reclassification`，共19项：18项通过，1项依赖可选原始UIEB冲突fixture而跳过；耗时97.613秒。执行时设置DCTTA_TEST_RDDM=1，真实RDDM测试没有跳过。

Python新入口通过语法编译；PowerShell运行脚本通过原生Parser语法检查。原始UIEB与历史算法文件没有改动。
