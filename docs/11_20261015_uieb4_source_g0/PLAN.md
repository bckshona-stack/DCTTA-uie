# 四类轻度源训练与重度 G0

数据协议：UIEB v2 轻度306张，按类别与已审核场景组分为244训练、62验证；重度172张做目标域；中度401张封存。原图逐字节保留。标签为AI视觉研究标注；近重复审核非穷尽，不能声称完全场景隔离。

源模型从头训练NU2Net-L1：250轮、batch16、patch256、Adam lr0.001、余弦调度、seed2022。每轮完整源验证，以源验证平均PSNR选best。保留原训练增强；不人为降低源模型指标。目标参考图不进入源训练、模型选择、Fisher或适配损失。

仅新增source_only与G0。G0保持RDDM持久在线学习、每图5次生成器更新、1次学生更新、完整再退化、教师EMA0.45、teacher_weight5、Fisher0.6、lr0.0002、seed23。针对新源权重和172张目标图重新计算并固定Fisher，禁止复用旧蓝色域缓存。

运行前严格确定性验收：至少22张，覆盖不同裁剪尺寸与RDDM EMA预热边界，核对重复运行、观测隔离和断点恢复的状态摘要。未通过则不启动正式G0。

固定10张目标图仅按类别及分辨率选择，不读取目标评分决定取舍；11个阶段保留teacher_pseudo、x_sd、y_sd、y_in整图和浮点/PNG PSNR，保存学生与教师权重。全目标集初态与末态评价并导出最终y_in。汇总总体均值、类别均值、类别等权均值以及逐图差值。

G0完整在线状态使用两个轮换槽和原子指针提交，保留初态及11个阶段小权重，避免逐步存1GB完整状态。所有G0输出受10GB磁盘峰值预算约束，预算不等于显存。源码/数据/模型/环境变化拒绝续跑。程序机CUDA验收和正式实验需用户执行；开发机只做CPU与合成数据验证。

Git：数据集阶段标签uieb-v2-dataset-20261015；本轮分支codex/uieb4-source-g0。历史算法文件保持不变；验证后提交并推送本分支。实验数据、结果、权重留在Git之外。
