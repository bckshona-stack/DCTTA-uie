## 2026-09-09：正式目标实验完成，出现显著负迁移

回传三组均 complete，均评价同一 133 张图。三组源权重及目标清单身份一致，实际 best.pth 和 target_eval.csv 的 SHA-256 匹配报告；model_config、空间处理、指标协议一致，输出图像三组尺寸逐图一致。DCTTA 完成 133 次适配，顺序包含 133 个不同样本。

| 方法 | 平均 PSNR / dB | 平均 SSIM |
|---|---:|---:|
| Source-only | 21.760601 | 0.877917 |
| Source-only+x8 | 21.822023 | 0.879856 |
| DCTTA | 15.018862 | 0.752982 |

相对 Source-only，DCTTA 平均 PSNR 下降 6.741739 dB，中位差 -6.757310 dB；131 张下降，2 张上升。SSIM 平均差 -0.124935，133 张全部下降。最严重 PSNR 下降为 507_img_.png（-14.012378 dB），其后 424_img_.png（-13.779645）、425_img_.png（-12.871309）。29 张小裁剪样本平均下降 8.060037 dB，104 张 320 裁剪样本平均下降 6.374137 dB；两组都是同一最终模型的评价结果，不能据此做小裁剪因果归因。

抽查 507_img_.png 与 299_img_.png 的 Source-only/DCTTA 输出，后者可见变暗和色彩偏移。全部输出图片先逐图取 RGB 均值再跨图平均：Source-only 为 (0.2904, 0.4348, 0.5280)，DCTTA 为 (0.2934, 0.3313, 0.3425)。这是保存图片上的输出变化，未与 reference 颜色做直接核查，不能将降低蓝通道单独解释为正确色偏校正。

适配权重全部有限。Fisher 共保护 1,887,542 / 3,145,923 个候选参数元素（约 60%），这些元素在最终模型中全部与源权重相等；其余 1,258,381 个元素均发生变化。保护机制执行成立，但不证明所选参数对 UIE 足够有效，也不能排除其他实现问题。

结论：本次配置下为明显、普遍的负迁移，不是源训练的轻度过拟合或少数离群值可以解释的现象。当前证据尚不能确定是伪标签漂移、RDDM 再退化质量、更新强度、NU2Net norm tail 与裁剪上下文作用，还是尚未发现的实现问题。当时未读到逐步损失，关于其缺失的判断已在2026-09-10更正；教师图、RDDM浮点中间结果及逐步模型快照仍缺失，无法定位首次退化步骤。未重新计算真实 raw/reference 上的指标，尚需原图进行进一步机制核查。

建议保留此次负结果与源基线，不覆盖、不根据目标 reference 扫描参数选择最佳配置。下一轮先做诊断：固定源权重与种子，记录逐步损失、教师伪标签、再退化图及原图/再退化图学生输出，检查输入范围与参数更新，并观察少量预定步骤的漂移。若用目标 reference 进行诊断，应将这批数据明确视为开发数据，最终结论另用未参与调参的数据验证。本轮未修改算法代码或启动新实验。
