# UIEB 四类轻／中／重重新划分

日期：2026-10-15。独立数据版本：UIEB_reclassified_v2。本轮只整理数据，不训练源模型或运行TTA。

## 已确认的协议

- 输入：E:\dataset\UIEB\raw-890 和 reference-890。
- 输出：项目 dataset/UIEB_reclassified_v2，原始图片不改动、不删除。
- 890对中，4组同raw异reference的8张全部隔离；另3组完全重复配对各留1张，共879对有效图片。保留同组中文件名按字典序最小者，记录所有排除依据。
- 不沿用旧四类标签、严重度评分和原weak/strong边界。
- 主类别限定 blue_tint / green_tint / hazy / low_light。每张只有一个主目录，另记其他退化类型及程度。
- 按可见退化实际程度判定，不三等分，不根据Source-only输出、PSNR或reference决定标签。
- 轻度用于后续源域，重度用于后续混合目标域；中度封存作为缓冲，不用于训练、适配或调参。
- 源模型仍应充分训练；本轮不以人为降低Source-only指标作为划分验收标准。

## 判定规则

每种退化记录0（无明显证据）、1（轻度）、2（中度）、3（重度）。这些是本次研究的可见退化操作标签，不是真实水体参数或官方标注。

- 偏蓝／偏绿：结合主体与背景判断普遍偏色和颜色可辨识性。蓝色水体、绿色植物或主体本身颜色不能单独证明严重偏色。重度应有广泛明显色偏、颜色分离受限等证据。
- 雾化：观察主体边界、远近层次、细节及整体对比度是否被散射幕显著遮蔽。离焦、纯色背景或本来平滑的物体不能单凭低对比度被判严重雾化。
- 低照度：观察大面积暗区、主体可见性及暗部细节。黑色物体或局部阴影不能单独当成严重低照度。
- 综合轻度要求所有已识别退化不超过1；任一明确3级可进入重度；其余进入中度。
- 主类别取对主体恢复影响最明显的一项，不按目录数量配平；复合情况写入CSV。
- 边界或难以从可见证据确定的图片保守进入中度，并记录不确定性，不强制放入轻／重两端。

## 执行与验收

1. 读取原始890对，核查配对、尺寸、解码、精确重复和reference冲突；生成879张可用清单。
2. 仅从raw计算新的RGB、亮度、对比度等辅助统计，并生成带文件名的联系表。统计只用于辅助检查，不能代替视觉标签；不使用旧评分。
3. 逐批查看879张原图的等比例预览，记录四项程度、主类别及边界情况。对疑难图补充大图检查。预览尺寸变化只用于审阅，最终复制不经过图像编码器。
4. 检查近重复候选，避免已识别同场景跨轻／重；不能将近重复启发式说成完整场景真值。
5. 复制原文件字节至 raw/<light|moderate|severe>/<主类别>/ 和 reference/同路径；保留扩展名和文件名，逐份核对文件SHA256。
6. 输出labels.csv、exclusions.csv、manifest、统计与说明；标注本次为单次研究标注，后续可复核，不能宣称客观物理真值或独立多人一致性。
